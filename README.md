\# AI Career Graph



A graph-powered career intelligence application built with \*\*CognoDB, FastAPI, Python, React and the official Neo4j Python driver\*\*.



The application models relationships between candidates, skills, jobs, companies, projects, technologies and learning resources to provide career recommendations and skill-gap analysis.

\## Features



\- Candidate career profile

\- Skill exploration

\- Project and technology relationships

\- Graph-based career recommendations

\- Multi-hop career path discovery

\- Skill-gap analysis for target jobs

\- CognoDB health monitoring

\- Loading and empty states

\- Graceful database/API error handling

\- Responsive web interface



\## Technology Stack



\### Backend

\- CognoDB Cloud



\### Frontend



\- React

\- Vite

\# Why a Graph Database?



Career data is highly connected.



A candidate does not simply have a list of skills. Their skills connect to projects, technologies, job requirements, companies and learning resources.
